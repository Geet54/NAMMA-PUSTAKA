# 📚 Namma-Pustaka

**Namma-Pustaka** is an Android application designed to digitize rural school libraries and make book access easier for students and teachers.

The app helps students discover books, view summaries, reserve books, and track reading progress, while teachers can efficiently manage borrowing records, overdue reminders, and library activities.

---

## 🌟 Features

### 📖 Book Catalog
- Browse available books
- View book details, summaries, and availability status

### 📱 QR Code Borrow System
- Borrow and return books using QR code scanning
- Fast and easy library transactions

### ⭐ Review & Rating System
- Students can rate books
- Write and read reviews from other readers

### 🏆 Reading Leaderboard
- Track student reading activity
- Encourage healthy reading competition

### 🔍 Smart Search
Search books by:
- Book Name
- Author Name

### 💾 Room Database Integration
- Offline local storage
- Fast and reliable data access

### ⏰ Overdue Reminders
- Teachers receive reminders for overdue books
- Better book return management

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **IDE:** Android Studio
- **Database:** Room Database
- **Architecture:** MVVM
- **QR Scanner:** ZXing / ML Kit
- **UI:** XML Layouts + Material Design Components
